## The 4 Stages in Detail

### Stage 1: Cognitive Scaffolding & Initial Flawed Generation

An AI coding agent drafts a FIFO write controller (`src/buggy_fifo_ctrl.v`). Syntactically, it passes basic compilation, but contains 3 severe semantic bugs:

1. Active-low reset polarity mismatch (`negedge rst_n` sensitivity paired with `if (rst_n)`).
2. Simulation race condition (blocking assignments `=` used for clocked registers).
3. Silent bitwidth truncation (8-bit bus assigned to 4-bit output).

### Stage 2: Static Semantic Audit ([`mcp-rtl-review`](https://github.com/zesun33/mcp-rtl-review))

The agent runs `rtl_review` on the draft.

- **Score**: `0 / 100` (5 Errors, 5 Warnings).
- **Rule Violations**:
  - `RESET_POLARITY_MISMATCH`: Line 14
  - `SEQ_BLOCKING_ASSIGN`: Lines 15, 16, 18, 19
  - `WIDTH_MISMATCH`: Line 25
- **Self-Healing**: The agent applies the exact remediation suggestions generated by the tool, producing `src/clean_fifo_ctrl.v`.
- **Re-Audit Score**: **`100 / 100`** (0 errors, 0 warnings).

### Stage 3: Functional Verification ([`mcp-verilog`](https://github.com/zesun33/mcp-verilog))

The agent runs `verilog_simulate` on `clean_fifo_ctrl.v` alongside `src/tb_fifo_ctrl.v`.

- **Simulator**: Icarus Verilog inside isolated container `localhost/zesun33/verilog`.
- **Assertion Result**: `ALL FIFO TESTS PASSED` (`$finish called at 45000 ps`).

### Stage 4: Latch Triage & Gate-Level Synthesis ([`mcp-yosys`](https://github.com/zesun33/mcp-yosys))

Before passing to physical design, the agent audits the netlist:

- `yosys_check_latch`: Confirms **`hasLatches: false`** (no unintended transparent latches inferred).
- `yosys_synthesize`: Synthesizes to generic logic cells:
  - Total cell count: **13 cells**
  - Breakdown: `5x $_DFFE_PN0P_`, `3x $_XOR_`, `2x $_AND_`, `1x $_ANDNOT_`, `1x $_NAND_`, `1x $_NOT_`.

To enable this full closed-loop flow in your IDE (**Cursor**, **Windsurf**, **GitHub Copilot / OpenAI Codex**, **Claude Code**, **Google Antigravity**, **OpenCode**, **Cline**), add all three servers to your configuration:

      "command": "node",
